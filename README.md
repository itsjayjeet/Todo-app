# To-Do App

A simple and responsive To-Do application built using HTML, CSS, and JavaScript. This project helps users manage their daily tasks through a clean and easy-to-use interface.

## Features

* Add new tasks
* Mark tasks as completed
* Delete tasks
* Simple and user-friendly interface
* Responsive design
* Basic task management functionality

## Technologies Used

 **HTML5** – Structure of the application
 **CSS3** – Styling and responsive layout
 **JavaScript** – Task management and user interactions

## Project Structure

```text
To-Do-App/
│
├── index.html
├── style.css
└── script.js
```

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.
4. Start adding and managing your tasks.
